# One Star, Written in Sap

> ★☆☆☆☆ He waters me once a month, then gasps like I died on purpose. I asked for sunlight, not a slow funeral in the corner. Would not photosynthesize here again.

`main.ts` holds the entry line as a constant, validates it (under 280 characters, a single line with no newline or control characters, no leading or trailing whitespace, and opening with the one-star rating), then writes it — with no trailing newline — to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), and finally reads the file back to confirm it matches the line byte-for-byte.
